# Deeper 100bb conditional flop — 2026-11-08

The preceding batch added lower-pot 20bb and 50bb studies. This candidate fills
the remaining 100bb gap: a complete Kc Td 4h game starting with a 24bb pot and
88bb behind. This leaves room for non-all-in raises and multi-street betting,
unlike the earlier 100bb studies' 60bb starting pots and 70bb behind.

It is a new conditional saved game, not a replacement, validation or release
of a universal 100bb policy. Starting ranges are illustrative study assumptions,
not certified frequencies from an earlier betting line. The existing sixteen
studies and full-hand model artifacts are unchanged.

## Fixed game and structural preflight

- BTN: AA / KQs / QJs — 13 board-legal combinations.
- BB: TT / KJs / AQs — 10 board-legal combinations.
- Equal inclusion per unblocked combination within each seat; private pairs
  are sampled jointly with exact card removal.
- 105 compatible starting pairs; 207,900 ordered deal–turn–river runouts.
- Half-pot, pot and all-in bets, plus the existing one-raise abstraction.
- One joint flop-to-river solve, not independently solved street policies.

The independent native census counts 412,300 public decisions, 1,059,468 public
nodes including chance/terminals, 4,359,834 combination rows and 10,578,022 action
cells. Exact regret/average arrays require 169,248,352 bytes. The game stays
within the existing 500,000-decision, 2,000,000-node, 32-combo-per-seat and 512MiB
accumulator caps; no branch, private hand or ordered arrival is pruned to fit.

A half-pot bet is 12bb. The modeled pot raise targets 60bb, below the 88bb
starting stack behind. After the caller adds 48bb, the turn pot is 144bb with
28bb behind each. The shared-engine regression must preserve this exact line,
subsequent streets, unique cards and 200bb chip conservation.

starting spot and ≤0.0001bb maximum discrepancy for every available action EV,
with valid frozen probabilities. Zero compatible opponent reach remains
explicitly unavailable and ungraded. Counterfactual action values follow the
same frozen policy through later streets; no online resolver, neural leaves or
sampling-based continuation is substituted.

This continues the existing static, version-pinned serving path and bounded

## Short pilot

The [128-update pilot](reports/2026-11-08-flop-100bb-deeper-128.json) reached
0.2389934179bb summed response gain and failed the unchanged 0.05bb gate. It
exported no serving artifact. Every available EV was checked: 9,902,077 values
across 4,068,524 combination rows, with maximum f32 discrepancy
0.00000381469728bb. The other 291,310 rows have no compatible opponent reach
and remain explicitly unavailable, not zero-loss grades.

The independent scalar/vector profile difference was 3.55e-15bb; payoff
conservation residual was zero. The run took 102.29s wall, including 91.17s
training and 10.61s checking, with about 540MB maximum RSS. These are local
measurements, not a general performance guarantee. The published-source
candidate advances to 512 updates in a fresh native export; no regret state or
partial training checkpoint is served.
